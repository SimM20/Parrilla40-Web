What your browser stores

Cookies and storage

Draft dated October 29, 2026. This describes the site's code. Production providers' cookies, logs and backups must be checked before an effective date is set.

Functional preferences

The site's JavaScript does not create cookies or include advertising or analytics tools. It saves the light or dark theme in your browser's local storage under parrilla40-theme. This lasts until you change it or clear site data and contains no personal identifier. Without a stored preference, the system preference is used.

Pausing animations only affects the page's memory; the site's motion also respects your system's reduced-motion preference.

Temporary survey state

The tab's session storage keeps a random identifier and whether submission for a build was confirmed under a key starting with parrilla40-playtest-v2:. When submission begins, it also saves the three answers, including optional text, only while confirmation is pending. Reloading or switching language in that tab restores the pending submission so the exact same answers can be retried without duplication.

The temporary answers are removed when confirmation arrives; the identifier and submission status remain for the session. Before starting a submission, what you write remains only in the form and in memory. This mechanism does not recognize a person across devices or tabs.

Pending signup, withdrawal link and private results

While an email signup is unconfirmed, parrilla40-launch-notice-pending temporarily keeps the email and its secret withdrawal code in session storage. This allows retrying after a reload without losing the same code. It does not include the survey identifier or answers. It is removed when confirmation arrives.

The withdrawal link contains that code in the address part beginning with #. Your browser does not send the fragment when requesting the page; it is used only to process withdrawal with Supabase. Save the confirmed link or download a copy in a text file: it is no longer retained as a site preference. Delete the file when no longer needed and keep the link private.

Without confirmation, pending data lasts until you clear storage or the tab session ends; your browser may restore sessions according to its settings. If you block session storage, retries work in the open page, but reloading may lose pending data. The password and private results remain only in memory during access; they are not stored as an administrator session.

Connections and providers

Fonts and images are served by this site. Form and results pages load a library from jsDelivr and connect to Supabase to submit data or validate access. The event leaderboard periodically queries another Supabase database while its page is visible. These providers and the hosting service receive technical connection information and may keep logs. Additional cookies and production retention periods still need checking.

No consent banner is added for advertising technologies that this code does not use. If analytics, tracking or other purposes are introduced, information and consent will be reviewed before activation.

Your controls

You can clear or block site storage in your browser. Preferences and temporary state will be lost and some functions may fail; clearing storage does not delete data already submitted to the database. To delete a signup use Withdraw consent. For data rights, see the Privacy Policy.
